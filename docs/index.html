07 / FAQ

QUESTIONS,
ANSWERED.

Is Orbit really 100% free?

Yes. Orbit is free and open-source under the MIT license. There are no paid tiers, no subscription paywalls, no daily quotas, and absolutely no ads.

Do I need to install FFmpeg or Python?

No! Unlike command-line yt-dlp tools, Orbit bundles both FFmpeg, FFprobe, and the entire runtime inside a single standalone executable (Orbit.exe). It works out of the box on any Windows 10 or 11 PC.

Which platforms can I download from?

Orbit supports YouTube, Shorts, TikTok, Instagram Reels, X (Twitter), Vimeo, Reddit, Twitch, SoundCloud, Bilibili, Facebook, Kick, Bluesky, Loom, and over 1,000 other websites supported by yt-dlp.

Where are my downloads saved?

By default, files are saved in your Downloads\Orbit Videos directory. You can customize the save directory to any drive or folder in the Orbit Settings tab.

Why does Windows SmartScreen show a blue warning?

Because Orbit is a brand-new open-source executable that is not code-signed with an expensive enterprise certificate. Simply click More info → Run anyway.

Can I download audio-only as MP3?

Yes. Select the "Audio" tab and choose MP3. Orbit extracts the highest quality audio stream and converts it into a clean MP3 file with embedded metadata.
